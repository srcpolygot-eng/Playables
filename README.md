# Playables

Self-contained HTML5 / CSS / TypeScript (and WebGL) games built for YouTube Playables.

## Games

| Folder | Title | Stack |
|--------|-------|-------|
| [Sudoku](./Sudoku) | Zenoku — Soft Minimal Paper Sudoku | TypeScript, Vite, CSS |

Each game lives in its own folder. Open the folder or deploy via Vercel with that root directory.
